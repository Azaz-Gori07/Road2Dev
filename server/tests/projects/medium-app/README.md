# Medium App

A medium-sized React application demonstrating full-stack architecture.

## Features
- React 18 with concurrent rendering
- React Router v6 for routing
- Zustand for state management
- Axios for API communication
- JWT authentication
- Responsive CSS design

## Getting Started
1. Install dependencies: `npm install`
2. Start development: `npm start`
3. Build for production: `npm run build`

## Architecture
The application follows a component-based architecture with:
- Pages directory for route-level components
- Components directory for reusable UI
- Context directory for React contexts
- Store directory for Zustand state
- Utils directory for utilities
