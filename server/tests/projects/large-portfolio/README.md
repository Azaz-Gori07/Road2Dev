# Large Portfolio Project

A comprehensive portfolio website built with React.

## Features
- 40+ reusable components
- 15+ pages with routing
- 20+ custom hooks
- 8 utility modules
- Responsive design
- Dark/light theme
- i18n support
- SEO optimized
- Analytics integration
- Cookie consent
- Accessibility features

## Tech Stack
- React 18
- React Router v6
- Zustand for state
- Axios for HTTP
- Framer Motion for animations
- Tailwind CSS for styling
- Express backend
- MongoDB database
- JWT authentication
- Socket.io for real-time
